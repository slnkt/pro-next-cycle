# Bioniq PRO: запуск услуг программы в любой момент

Кликабельный прототип мобильного приложения (iPhone 390×844) по ТЗ «PRO 6 / 12 мес, запуск услуг программы в любой момент» (v1 от 28.09.2026).

Страница: https://slnkt.github.io/pro-next-cycle/

## Что внутри
- Главная как в текущем приложении: шапка, сторис, баннер, тёмная карточка приёма с календарём, карточка PRO, аналитика, рекомендация, таб-бар
- Блок «Ваша программа» в карточке PRO: остаток по трём услугам и кнопка на каждую (консультация «Записаться», чекап «Записаться», витамины «Заказать»). При остатке 0 кнопки нет, пока комплекс в производстве или доставке «Заказать» неактивна
- Экран заказа комплекса (шторка снизу): «Комплекс N из M», срок и ориентировочная дата, формула по рекомендации с «Изучить формулу» (экран «Рецепт»), «Что-то изменилось в анкете здоровья?» Нет / Да (Да открывает анкету), адрес с «Изменить», кнопка «Заказать» → карточка в «Идёт производство»
- Параллельные статусы стопкой в карточке PRO, как сейчас «комплекс + консультация»
- Чекап и консультация через существующие флоу: заявка в три шага и «Запись на консультацию»
- Запуск из OFS (менеджер или КС) выглядит для клиента так же: кнопки в панели демо

## Панель демо
Тариф, какой комплекс клиент принимает сейчас (остаток считается от него), запуск услуг из OFS, переключение этапов трёх услуг, сброс.

Один файл `index.html`, без сборки. Предыдущая версия прототипа (с напоминанием за месяц и пушем) сохранена как `v3.html`.
