# Bioniq PRO: запуск следующего цикла

Кликабельный прототип мобильного приложения (iPhone 390×844) для сценария «запуск цикла 2 и далее» программы PRO. Экраны собраны по макетам и записи экрана текущего приложения: шапка с баллами, сторис, баннер, карточка программы с пунктирной рамкой и прогресс-баром, тёмная карточка приёма с календарём, «Аналитика», «Рекомендация», таб-бар.

Страница: https://slnkt.github.io/pro-next-cycle/

## Что внутри
- Главная с карточкой PRO, блоком остатка программы (комплексы, чекапы, консультации), показателями, рекомендациями и таб-баром
- Экран блокировки с пушем за месяц до конца комплекса
- Блок «Пора заказать следующий комплекс» в карточке, bottom sheet: анкета здоровья → адрес доставки → запись на забор крови (если в цикле чекап, можно отложить и оставить заявку из карточки) → готово
- Заявка на забор крови в три шага, как в приложении: способ сдачи → ваши данные → лаборатория и дата → «Ваша заявка создана!»
- Запись на консультацию: дата, время, формат → «Запись создана!» с врачом, в карточке появляется строка «Ожидайте консультацию с врачом»
- При переключении этапов сверху всплывает пуш с текстом, как в приложении
- Статусы цикла с названиями из макетов: без чекапа («Идет производство комплекса под вас» → «Ваш витаминный комплекс уже готов и спешит к вам» → «Уже получили заказ?» → приём) и с чекапом («Оставить заявку на забор крови» → «Ожидайте назначения забора крови» → «Ожидайте забора крови» → «Результаты анализов готовятся» → «Готовим формулу витаминного комплекса» → «Комплекс ожидает производство» с консультацией → производство → доставка → «Уже получили заказ?» → приём)
- Путь запуска менеджером: в карточке блок от менеджера с адресом, ссылки «Изменить адрес» и «Выбрать дату забора крови»

## Панель демо
Тариф (PRO 6 мес, PRO 12 мес с 2 или 4 чекапами), номер цикла, чекап в цикле, кто запускает (клиент или менеджер), кнопка пуша, переключение этапов цикла, сброс.

Один файл `index.html`, без сборки.
